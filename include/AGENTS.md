# include/

Public headers. They define the contract for `src/`.

- Keep implementation details in `.c` files. Do not put struct layouts or state in public headers unless the API needs them.
- Every header needs an include guard. Include the headers it uses directly instead of relying on include order.
- `libargs.h` is the public C API. Keep `ArgCheck` opaque and keep the `extern "C"` guard for C++ consumers.
- Put `ARGCHECK_NORETURN` and printf-format attributes on declarations so every caller sees them.
- `common/common.h` is the umbrella include for `src/common/`. Keep it declarations and includes only, with no state or logic.
- `common/bundled-firmware.h` is generated by `scripts/generate_firmware_header.sh` and gitignored. Do not edit it; include it only under `#ifdef BUNDLED_FIRMWARE`. It defines `BUNDLED_<CHIP>` for each bundled chip; backends gate bundled use on their own macro.
- `common/version.h` is generated at build time and gitignored. Do not edit it; only `src/common/version.c` includes it, and `common/common.h` exposes `print_version`.
- `common/essential-memory.h` owns `EssentialMemoryEntry` (including `role`), `map_essential_memory`, `load_firmware`, and `load_bundled_binary`. Keep the mapper/loader chip-agnostic; chip tables live in `H1B3C/memory.h`.
- `common/memory-fault.h` owns `install_memory_fault_hook` and `memory_fault_occurred`. It logs unmapped/protected accesses with the address and PC, sets an atomic fault flag, and calls `uc_emu_stop`; keep the hook free of `emu_exit`/`uc_close`.
- `common/runtime/control.h` owns `Runtime`, `runtime_init`, `runtime_fault`, `runtime_start_emulation`, and `runtime_run`. `runtime_fault` is the only fatal path callable from any thread; `runtime_run` owns teardown and the control poll loop.
- `common/runtime/thread.h` owns `ThreadCtx` and the `tctx` thread-local (role, name, worker, component, MMIO PC snapshot). Keep it labels and scratch only; never store `ctx.uc`, `ctx.ac`, or the component array in it.
- `common/runtime/worker.h` owns `Worker`, `WorkerOp`, `worker_start`, `worker_stop`, `worker_read`, and `worker_write`. Reads and default writes are synchronous; async writes are opt-in.
- `common/runtime/console.h` owns `console_start` / `console_stop`, the stdio pumps used by the control poll loop, and the UART-side pty master read/write helpers. T2 creates the pty; T0 owns stdio and the slave side; UART owns the master side.
- `common/vtor.h` owns `set_sp_pc`. It takes the engine and vector-table base so chip callers stay in control of the address.
- `common/sha256.h` owns the `Sha256Context` API used by the KEYMGR SHA engine. Keep it dependency-free and chip-agnostic.
- `common/aes.h` owns the `AesContext` block-cipher API used by the KEYMGR AES engine. It covers 128/192/256-bit keys and single-block encrypt/decrypt; modes and FIFOs stay in the chip component.
- `common/ctx.h` declares the global `Ctx ctx` container and `ctx_init`. Keep it a plain data struct; resource ownership stays with the code that created the resource, and `ctx.verbose` is the only verbose switch. `ctx.firmware` holds the fixed `char[MAX_FILE_PATH]` paths plus the `useBundledROM`/`useBundledFW` flags; `main` fills them from `--bootrom`/`--firmware` and the backend decides whether to read a file or use the bundled arrays. Copy CLI strings in, never store `ArgCheck` pointers.
- `common/emulator.h` owns `Emulator` and `EmulatorChips`. Keep them chip-agnostic. Adding a field or changing a function pointer signature requires updating every backend and `get_chipemu`.
- `common/exit.h` exposes `emu_exit`; it must stay `ARGCHECK_NORETURN` and control-thread-only.
- `common/rc.h` owns `Rc`. Every exit path uses an `RC_*` value; add a new one instead of reusing an unrelated code.
- `common/file.h` owns `FileRC` and the file helpers. Keep them free of `ctx` and `emu_exit`; they report failures with a code and treat `buffer_size` as including the trailing NUL.
- `common/peripherals/component.h` owns the generic `Component` (including `Worker *worker`), `MmioRegion`, registry, mapping helpers, threaded registration, `component_stop_all`, and `component_log_unhandled`. Keep it chip-agnostic.
- `common/peripherals/define.h` owns `DEFINE_BASIC_REGISTER` (storage only), `BasicRegister`, `BASIC_REGISTER_ENTRY`, `basic_register_find`, and `ARRAY_LEN`. Use one table entry per plain register; keep switch cases only for side effects, read-only/constant values, validation, or per-instance/array state.
- `H1B3C/peripherals.h` defines `DEFAULT_REG_LENGTH` and includes the per-peripheral headers; `H1B3C/peripherals/<name>.h` owns that peripheral's base address, register offsets, and init entry point. Keep every offset 4-byte aligned and add new registers to the matching peripheral header.
- `H1B3C/memory.h` owns the H1B3C region macros and declares `H1B3C_EssentialMemoryArray`; define the table in `src/H1B3C/memory.c`.
- `H1B3C/peripherals/*.h` expose component init entry points; `initialize_peripherals` stays in `H1B3C/peripherals.h`.
- `H1B3C/peripherals/crypto-engine.h` exposes the CRYPTO bignum program engine (IMEM/DMEM access plus a run entry point). Keep its state inside `crypto-engine.c`; the component owns the register interface.
- Chip headers expose only lifecycle entry points. Chip-specific state and helpers stay in `src/<chip>/`.
- Keep prototypes in sync with definitions. A header change is not complete until all implementations, `main.c`, and the fuzz harness compile.
